# 📝 Quick Notes Application

A simple and user-friendly Quick Notes Application built using Python, Flask, and SQLite.

## 🚀 Features

- Create new notes
- Save notes in SQLite database
- Display all saved notes
- Delete notes
- Simple and clean user interface
- Data persistence

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## 📂 Project Structure

```text
Quick-Note-Application/
│
├── app.py
├── database.py
├── requirements.txt
│
└── templates/
    └── index.html
```

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd Quick-Note-Application
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

5. Open your browser:

```text
http://127.0.0.1:5000
```

## 💾 Database

SQLite is used to store notes permanently. The database table is created automatically when the application starts.
